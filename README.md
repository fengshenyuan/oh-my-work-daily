# oh-my-work-daily

This is a private GitHub repo mainly used to record daily work and long-term research notes, especially notes that may not be suitable for public sharing.

## Long-term principles

### 中文

- **卖 Intelligence，而不是卖 Workflow。**
- **研究 Agent 的长期本质，而不是追逐业界的短期喧嚣。**
- **Measurement / Metrics 是稀缺的世界资源。**

### English

- **Sell Intelligence, not Workflow.**
- **Bet on Agent fundamentals, not Agent hype.**
- **Measure the world; measurement is scarce.**
